# GA4 E-Commerce Funnel Analytics

## Business objective

Turn event-level Google Analytics sample data into a management view of the e-commerce funnel: acquisition, engagement, product interaction, checkout, and purchase.

## Dataset provenance

This project uses Google's public **GA4 obfuscated sample e-commerce dataset** in BigQuery. Google documents it as a three-month sample of Google Analytics BigQuery export data for the Google Merchandise Store. citeturn0search0

**Original data source:** Google Analytics / BigQuery Public Datasets.

> The underlying event data is Google's public sample. The funnel definitions, SQL transformations, analysis, visualizations, and recommendations in this repository are independent portfolio work.

## Originality

This repository is independently structured and does not reproduce another analyst's SQL, notebook, README, or conclusions.

## Questions

- Where does the user journey lose the most users?
- How do acquisition channels differ in engagement and purchase behavior?
- Which device or geographic segments show meaningful funnel differences?
- Which metrics should a growth team monitor weekly?
