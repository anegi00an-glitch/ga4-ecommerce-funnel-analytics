# Dashboard specification

## Executive funnel

**KPI cards:** Users · Product viewers · Cart users · Checkout users · Purchasers

**Funnel:** Product view → Add to cart → Begin checkout → Purchase

**Acquisition:** Purchase rate by source / medium, filtered to segments with sufficient volume

**Trend:** Daily users and purchase rate

**Segments:** Country and device category

The dashboard is designed for Power BI after exporting BigQuery query outputs. The public GA4 sample is used for learning/portfolio analysis, not as a claim about Google's commercial performance.
